# Polityka Prywatności / Privacy Policy for Yomitan Mobile

## 1. Zakres danych / Data scope

Yomitan Mobile nie wymaga konta i nie zbiera danych osobowych w centralnym backendzie.

Yomitan Mobile does not require an account and does not collect personal data in a central backend.

Domyślnie dane użytkownika, na przykład historia wyszukiwań, ustawienia i lista eksportów, są przechowywane lokalnie na urządzeniu.

By default, user data such as search history, settings, and export lists is stored locally on the device.

## 2. Kiedy aplikacja łączy się z internetem / When the app connects to the internet

Aplikacja może używać sieci w dwóch scenariuszach.

The app may use the network in two scenarios.

1. Pobieranie słowników na życzenie użytkownika.
1. Downloading dictionaries on user request.

2. Opcjonalne pobieranie zdań przykładowych z zewnętrznego API, tylko po wyrażeniu zgody.
2. Optional fetching of example sentences from an external API, only with consent.

## 3. Opcjonalne API zdań / Optional sentence API

Funkcja zdań online jest dobrowolna i domyślnie wyłączona.

The online sentence feature is optional and disabled by default.

Po włączeniu aplikacja wysyła zapytanie zawierające szukane słowo do zewnętrznego API wyłącznie w celu pobrania przykładowego zdania.

When enabled, the app sends the searched word to an external sentence API solely to fetch an example sentence.

Zgodę można w każdej chwili cofnąć w ustawieniach aplikacji.

Consent can be revoked at any time in the app settings.

## 4. Przechowywanie lokalne / Local storage

Dane tworzone przez aplikację, między innymi historia wyszukiwań, preferencje i metadane eksportu do Anki, są przechowywane lokalnie.

Data created by the app, including search history, preferences, and Anki export metadata, is stored locally.

Użytkownik może usunąć je przez wyczyszczenie danych aplikacji w ustawieniach systemu Android.

You can delete it by clearing app data in Android system settings.

## 5. Integracja z AnkiDroid / AnkiDroid integration

Eksport do AnkiDroid wykorzystuje oficjalne API AnkiDroid i lokalny mechanizm Content Provider.

Export to AnkiDroid uses the official AnkiDroid API and a local Content Provider mechanism.

## 6. Kontakt / Contact

W razie pytań lub wątpliwości dotyczących prywatności prosimy o otwarcie zgłoszenia w repozytorium projektu.

If you have questions or privacy concerns, please open an Issue in the project repository.

# Polityka Prywatności aplikacji Yomitan Mobile

## 1. Zakres danych

Yomitan Mobile nie wymaga konta i nie zbiera danych osobowych w centralnym backendzie.

Domyslnie dane uzytkownika (np. historia wyszukiwan, ustawienia, lista eksportow) sa przechowywane lokalnie na urzadzeniu.

## 2. Kiedy aplikacja laczy sie z internetem

Aplikacja moze uzywac sieci w dwoch scenariuszach:

1. Pobieranie slownikow na zyczenie uzytkownika.
2. Opcjonalne pobieranie zdan przykladowych z zewnetrznego API (tylko po wyrazeniu zgody).

## 3. Opcjonalne API zdan

Funkcja zdan online jest dobrowolna i domyslnie wylaczona.

Po wlaczeniu aplikacja wysyla zapytanie zawierajace szukane slowo do zewnetrznego API zdan wyłącznie w celu pobrania przykladowego zdania.

Zgode mozna w kazdej chwili cofnac w ustawieniach aplikacji.

## 4. Przechowywanie lokalne

Dane tworzone przez aplikacje (m.in. historia wyszukiwan, preferencje, metadane eksportu do Anki) sa przechowywane lokalnie.

Uzytkownik moze usunac je przez wyczyszczenie danych aplikacji w ustawieniach systemu Android.

## 5. Integracja z AnkiDroid

Eksport do AnkiDroid wykorzystuje oficjalne API AnkiDroid i lokalny mechanizm Content Provider.

## 6. Kontakt

W razie pytan lub watpliwosci dotyczacych prywatnosci prosimy o otwarcie zgłoszenia (Issue) w repozytorium projektu.
